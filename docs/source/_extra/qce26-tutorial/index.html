02 / Information

Target audience

The tutorial is aimed at software developers, computational scientists, graduate students, and industry practitioners.

  • Expected background Working knowledge of Python and a basic familiarity with introductory quantum computing concepts.
  • Prerequisites for hands-on participation A laptop with VS Code, the Microsoft QDK extension, and a working Python 3.10+ environment.
