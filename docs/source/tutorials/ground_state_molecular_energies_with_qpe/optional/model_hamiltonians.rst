Model hamiltonians
##################

.. note:: Chapter focus

   When can a model Hamiltonian replace the molecular electronic Hamiltonian?

Learning objectives
===================

After completing this chapter, you will be able to:

- Distinguish ab initio molecular Hamiltonians from model Hamiltonians.
- Identify the degrees of freedom and parameters in selected lattice models.
- Construct a model Hamiltonian with :term:`QDK`/Chemistry.
- Determine which steps of the required molecular workflow still apply.
- State the assumptions introduced by using a model.
