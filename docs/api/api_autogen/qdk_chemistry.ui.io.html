qdk_chemistry.ui.io.resolve_project_file(filename, *, allow_nested=False, allow_absolute=False)

Resolve a client-provided filename inside the current project sandbox.

Absolute paths, traversal components, Windows drive or UNC paths, and symlinks that resolve outside the project are rejected.

Parameters:

  • filename (str | Path) – Project-relative filename to resolve.

  • allow_nested (bool) – Whether ordinary nested path components are accepted.

  • allow_absolute (bool) – Whether an internal absolute path may be revalidated.

Return type:

Path

Returns:

An absolute path contained by the current project directory.

Raises:

  • RuntimeError – If called outside a validated project context.

  • ValueError – If the filename is invalid or escapes the project.
