Configuration class for QDK/Chemistry MCP Server.

In general, the agent will work in a dedicated project directory, where the directory structure is like:

scratch/projects/ ├── project1/ │ ├── water.structure.json │ ├── water.orbitals.json │ └── water.wavefunction.json ├── project2/ │ ├── n2.structure.json │ ├── n2.orbitals.json │ └── n2.wavefunction.json
